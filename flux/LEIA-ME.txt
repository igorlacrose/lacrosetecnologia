LACROSE FluX — Controle Financeiro | PWA

PUBLICAÇÃO
1. Extraia o ZIP e publique todos os arquivos da pasta no mesmo diretório de uma hospedagem HTTPS. Não exige instalação de dependências nem compilação.
2. Sirva index.html como página inicial. Use application/manifest+json para manifest.webmanifest e text/javascript para os arquivos .js. Evite cache HTTP prolongado para index.html, manifest.webmanifest e service-worker.js (preferir Cache-Control: no-cache).
3. Abra o endereço com internet e aguarde “Pronto para uso offline neste dispositivo”. Abrir o HTML diretamente como arquivo não habilita a PWA.
4. No iPhone: Safari > Compartilhar > Adicionar à Tela de Início. Abra pelo ícone e aguarde a preparação offline também nesse modo.
5. Ative modo avião, feche e reabra pelo ícone e confira login, lançamentos e gráficos. Teste também rotação, teclado, download/compartilhamento de CSV, Excel e JSON e importação pelo app Arquivos.

SENHA E DADOS
Senha inicial: 102030. “Alterar senha” mantém a nova senha neste dispositivo. A opção de restaurar a senha original foi preservada. O login é uma barreira local, sem autenticação de servidor nem criptografia dos lançamentos.
As chaves originais lacrose_financeiro_final, lacrose_senha_v4 e lacrose_ok foram preservadas. O service worker apenas armazena arquivos do aplicativo e remove versões antigas de seu próprio cache; não apaga localStorage.
Os dados atuais do navegador não estão dentro do HTML nem deste ZIP. Dados e senha são separados por origem e por perfil/dispositivo. Ao migrar de arquivo local para HTTPS ou entre dispositivos, exporte CSV e Backup JSON antes. Importe o CSV na nova origem uma única vez (a importação adiciona registros). Redefina a senha no novo endereço. Safari e o aplicativo instalado podem usar armazenamentos separados; confira o conteúdo antes de continuar. Não há sincronização automática. O backup JSON é exportável; o importador preservado é CSV.
Não limpe os dados do site para atualizar. Mantenha backups, pois o navegador/sistema pode remover armazenamento local. Nenhum dado de teste foi incluído no pacote.

ATUALIZAÇÕES
